# Aero

Aero is a programming language currently under construction.

## Building

Bazel is used for the build system. To build all targets:

```sh
$ bazel build //...

# or using `just`
$ just build
```

## Testing

To run all tests:

```sh
$ bazel test //...

# or using `just`
$ just test
```
